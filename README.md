# Praktikum Pemrograman Web

## Modul 4

### PHP REST API DAN MYSQL DATABASE

#### CodeLab
1. Menentukan tema web yang akan digunakan (sampai modul 6)
2. Melakukan interaksi ke MYSQL menggunakan PHP dengan 4 endpoint

#### Tugas Demo
1. Tugas 1 (Frontend): 
Buatlah sebuah Front End untuk website menggunakan HTML, CSS dan JS
sesuai dengan tema yang sudah di isi pada codelab minggu lalu. Pastikan pada
website terdapat komponen seperti navbar, main content dan footer.
(semakin banyak konten semakin baik)

2. Tugas 2 (Backend): 
Buatlah sebuah Create, Read, Update, Delete (CRUD) Endpoint API backend
seperti pada contoh materi diatas dan buatlah collection pada Postman yang
berisi Endpoint yang buat masing - masing sesuai dengan HTTP Method (GET,
POST, PUT, DELETE) seperti gambar berikut
